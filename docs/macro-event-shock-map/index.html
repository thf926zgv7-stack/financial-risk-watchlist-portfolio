宏观事件—资产冲击地图

把风险事件、市场数据与可核验的事件窗口放在同一张图里。用于复盘和研究，不用于预测。

分析边界：页面呈现事件日后 5 个可得交易日的变动，并展示前后各 5 个交易日的轨迹。它描述同时段的市场反应，不能单独证明事件造成了价格变化，也不构成投资建议。

选择事件

市场数据：Federal Reserve Economic Data (FRED)；构建日期与样本范围见仓库 README。

如何读这张地图

股票、原油与 VIX以百分比变化表示；10 年期美债收益率以基点（bp）变化表示。红色是上升，绿色是下降，颜色本身不代表好坏。
